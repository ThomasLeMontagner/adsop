# A System Engineering Model

An MBSE project is created with Capella in order to understand the mission, scope and main components on the system. This model captures my current understanding and will change as implementation reveals incorrect assumptions. It is not intended to be the source of truth as it may provide an incomplete picture of the software platform features. 

The goals of the model are:
* for myself to think and communicate;
* to represent the operational needs;
* to establish the system boundary;
* to define the main capabilities;
* to identify logical components and interfaces;
