# Getting Started

## Development Environment

ADSOP uses a lightweight and reproducible local development environment. PostgreSQL and other shared dependencies are initially provided through Docker Compose, while the frontend, backend, and simulation environment can be run directly using their native development toolchains for fast feedback and debugging. Common setup, build, test, and execution tasks are exposed through a small set of project-level commands. Automated formatting, linting, and testing are performed through GitHub Actions. The environment will evolve towards fully containerized execution as the platform matures.

## Prerequisites

- Go
- Rust
- Node.js
- Docker
- Docker Compose
