# Architecture Decision Records (ADRs)

This directory contains the Architecture Decision Records (ADRs) for ADSOP.

ADRs document important architectural decisions made throughout the project, including the context, the chosen solution, and its consequences. They provide an history of how the architecture evolves over time and help explain the rationale behind key design choices.

ADRs follow the format proposed by Michael Nygard and are numbered chronologically. New ADRs should be added rather than modifying past decisions whenever possible, allowing the project's architectural evolution to remain traceable.

## Naming Convention

ADRs are named using the following format:

```
0001_short_title.md
0002_short_title.md
0003_short_title.md
```

For example:

```
0001_use_a_monorepo.md
0002_use_a_modular_monolith.md
0003_use_https-and_websockets.md
```
